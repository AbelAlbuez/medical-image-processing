# Cohort

This directory defines the stratified BraTS 2024 GLI cohort.

- `stratify_brats.py` characterizes the gated BraTS training data and samples
  the cohort.
- `STRATIFICATION_SPEC.md` documents axes and sampling rationale.
- `COHORT_MANIFEST.md` is the 150-case cohort manifest.
- `COHORT_MANIFEST_selected.csv` is the machine-readable 100 process-case list
  with fold assignments.

The raw BraTS data are not redistributable and must remain git-ignored.
